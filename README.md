# research-hub

설치 없이 브라우저에서 바로 쓰는 연구용 웹 도구 모음입니다. 각 도구는 HTML 파일 하나로 되어 있어서, 내려받아 열거나 GitHub Pages 주소로 접속하면 됩니다.

| 도구 | 파일 | 하는 일 |
|---|---|---|
| 나의 연구 허브 | [`index.html`](index.html) | 논문 검색, 정리, 요약, 리서치 도구 |
| 실험 도구모음 | [`lab-tools/index.html`](lab-tools/index.html) | BCA assay 표준곡선, 몰농도 계산기 |

## 사용 방법

**웹에서 열기**

저장소의 Settings → Pages에서 `main` 브랜치를 배포하면 아래 주소로 열립니다.

- 연구 허브: `https://tuna616.github.io/research-hub/`
- 실험 도구모음: `https://tuna616.github.io/research-hub/lab-tools/`

**내 컴퓨터에서 열기**

저장소를 내려받고(Code → Download ZIP) `index.html`을 브라우저로 엽니다. 글꼴과 일부 라이브러리를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 나의 연구 허브

- **통합 검색**: 키워드 하나로 Crossref, OpenAlex, Semantic Scholar, Europe PMC, PubMed를 한 번에 검색합니다.
- **논문 정리함**: 논문을 폴더로 정리하고 한국어·영어 요약, 연구 노트, 질문, Figure·표, 서지정보를 논문별로 모아 봅니다.
- **리서치 도구**: 정리함의 논문이나 새로 첨부한 파일(PDF, DOCX, XLSX, PPTX 등)을 대상으로 여러 분석 도구를 실행합니다.
- **저널 관리**: 검색 결과를 걸러낼 저널 목록을 직접 관리합니다.
- **개인화**: 사이트 이름과 연구 주제를 설정에서 바꿀 수 있습니다.

요약 같은 AI 기능은 설정에 본인의 API 키를 넣어야 동작합니다. 키가 없어도 검색과 정리는 쓸 수 있습니다.

## 실험 도구모음

### BCA assay 표준곡선

- 표준(BSA) 농도와 562 nm 흡광도를 넣으면 표준곡선과 식, R²를 보여줍니다. 반복 측정은 3개까지 넣을 수 있고 평균 ± SD로 그립니다.
- 피팅은 선형과 2차 다항식 중에서 고릅니다. 농도 0 표준을 blank로 빼는 옵션이 있습니다.
- 샘플 흡광도와 희석배수를 넣으면 원액 농도를 계산하고, 표준 범위를 벗어난 샘플을 표시합니다.
- 로딩 계산: 1개당 단백질량과 부피, 샘플 버퍼 배수, 만들 개수를 넣으면 lysate·버퍼·DW 부피와 총 부피를 계산합니다.
- 엑셀이나 plate reader 결과를 표에 그대로 붙여넣을 수 있고, 방향키와 Enter로 칸을 이동합니다.
- 그래프는 이미지로, 결과와 로딩 표는 엑셀 붙여넣기용으로 복사하거나 CSV로 저장합니다.

### 몰농도 계산기

- 분자량을 직접 넣거나 화학식(예: `C6H12O6`, `CuSO4·5H2O`)으로 계산합니다.
- 분말 ↔ 용액: 질량, 부피, 농도 중 둘을 넣으면 나머지를 구합니다. 순도 보정을 지원합니다.
- 희석: C₁V₁ = C₂V₂로 stock을 얼마나 떠야 하는지 구합니다.
- 단위 변환: 몰농도와 질량 농도(mg/mL, % w/v 등)를 서로 바꿉니다.

## 데이터와 개인정보

- 서버가 없습니다. 입력한 값, 정리한 논문, API 키는 사용 중인 브라우저에만 저장됩니다.
- 그래서 기기나 브라우저를 바꾸면 데이터가 따라오지 않고, 브라우저 데이터를 지우면 함께 사라집니다. 중요한 내용은 내보내기로 따로 보관하세요.
- 논문 검색과 AI 기능을 쓸 때는 검색어나 논문 내용이 해당 서비스(Crossref, OpenAlex, Semantic Scholar, Europe PMC, PubMed, 사용자가 키를 넣은 AI 제공자)로 전송됩니다.

## 주의

계산 결과는 실험 준비를 돕기 위한 것입니다. 중요한 실험에서는 식과 단위를 직접 한 번 더 확인하세요. 실험 도구모음의 표와 그래프는 처음 열면 예시 데이터로 채워져 있습니다.
